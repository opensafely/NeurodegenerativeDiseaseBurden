# Script overview

This repository contains the following scripts:

- [**codelists/**](./codelists/)
  - **\*.csv**: Codelists for each variable defined in this study, downloaded by `opensafely codelists update`.
  - [**codelists.json**](./codelists/codelists.json): JSON list of codelists automatically generated by `opensafely codelists update`.
  - [**codelists.txt**](./codelists/codelists.txt): User defined list of codelists for this study.
- [**project.yaml**](./project.yaml): The project pipeline used for executing the code and detailing dependencies. This file should not be edited directly. To make changes, edit and run [create_project_actions.R](./analysis/create_project_actions.R).
- [**analysis/**](./analysis/)
  - [**create_project_actions.R**](./analysis/create_project_actions.R): R script to automatically generate `project.yaml` file. 
  - [**dataset_definition/**](./analysis/dataset_definition/)
    - [**dataset_definition.py**](./analysis/dataset_definition/dataset_definition_prevax.py): Generates the dataset using start and ene dates specified in [project.yaml](./project.yaml).
    - [**dataset_definition_cohorts.py**](./analysis/dataset_definition/dataset_definition_cohorts.py): Defines the common elements of all cohorts using user specified index dates, cohort start date and cohort end date. 
    - [**dataset_definition_dates.py**](./analysis/dataset_definition/dataset_definition_dates.py): Generates a dataset of key dates that is used by all other `dataset_definition_*.py` scripts.
    - [**variable_helper_functions.py**](./analysis/dataset_definition/variable_helper_functions.py): Defines ehrQL functions for variable creation.
    - [**codelists.py**](./analysis/dataset_definition/codelists.py): Creates codelist variables that can be accessed by [`variables_cohorts.R`](./analysis/variables_cohorts.py).
